# Encryptor-GUI (Version 2.0.0)
Use Encryptor-GUI for a better and easier user experience.  
It performs the same tasks as Encryptor-Console but provides a GUI for improved usability.

---

## Usage
* Extract the downloaded file.
* Navigate to the `encryptor-gui-2.0.0` directory.
* Execute `Encryptor-GUI.bat`.

---

## Requirements
* **JRE 8u441 or later, or JDK 8u441 or later**

---

## Note
- `Encryptor-Console` must be in the same directory of Encryptor-GUI to perform tasks.
- Please verify the file checksums (SHA-256) before using Encryptor.
