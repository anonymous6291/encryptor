# Encryptor (Version 2.0.0)

Encryptor is a software that encrypts or decrypts files using your password. It accepts multiple files and folders as input and performs operations recursively and concurrently. Additionally, it hides file names (not folder names) for better confidentiality.  
**Encrypted files are created in the parent directory of the given paths.**

---

## Supported Operating Systems
- **Linux**
- **Windows 11**
- **Mac**

## Supported Modes
- **Linux**
   > Console and GUI mode  
- **Windows**
   > Console and GUI mode 
- **Mac**
   > Console and GUI mode

---

## Requirements
- **Console Mode**
   > Terminal  
- **GUI Mode**
   > JRE 8u441 or later, or JDK 8u441 or later

---

## Tested On
- **Linux 6.8.0-51-generic**  
- **Windows 11**
- **Mac OS 15.3**

---

## Notes
- There is **no backward compatibility** with version 1.x.x. Files encrypted with 1.x.x cannot be decrypted with 2.x.x and vice versa.
- Please verify the file checksums (SHA-256) before using Encryptor.
- GitHub's web interface may take a few seconds to start downloading files. If the download does not begin immediately, please wait a moment before trying again.
